# Sensor Daddy (Original) face

This KSysGuard face is the companion package for Sensor Daddy 2.7. It registers
`Sensor Daddy (Original)` in KDE's native Display Style dropdown. The Sensor
Daddy applet recognizes this face ID and renders its original compact text row
instead of the face's placeholder representation.

Do not rename the face ID:

```text
org.kde.ksysguard.sensordaddyoriginal
```

The main maintenance documentation is:

```text
../org.kde.plasma.sensortempmonitor/AI_MAINTENANCE.md
```
